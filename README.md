# Description
These are a series of short exercises designed to teach the basics of Python. Each module centres around a certain skill that needs to be achieved in order to effectiviely code in Python. 

## Module 00
The absolute basics, handling prompted input, output, using variables and formatting.

## Module 01
Classes and methods. This module teaches how to set up and use classes, methods, inheritence, secure classes and subclasses.

## Module 02
Error handling. This module teaches error handling with try, except, finally and creating custom error classes.

## Module 03
Handling data. This module teaches how to handle command line arguments and store data in lists, tuples, dictionaries etc.
